## 🛠️ ¿Qué encontrarás en este portal?

Para apoyarte en cada etapa de tu formación académica, hemos estructurado los contenidos en cuatro pilares fundamentales:

| Recurso | Descripción |
| :--- | :--- |
| 📝 **Ejercicios Propuestos** | Desafíos diseñados para poner a prueba tus conocimientos y desarrollar tu pensamiento crítico. |
| ✅ **Ejercicios Resueltos** | Soluciones paso a paso para guiarte en la resolución de problemas complejos. |
| 📚 **Fundamentos Teóricos** | Resúmenes teóricos, fórmulas y esquemas organizados por materia para facilitar tu estudio. |
| 📝 **Exámenes y Prácticas** | Evaluaciones pasadas y simulacros para preparar tus parciales con total confianza. |

## 🗺️ Navegación por el Portal

¡Explorar el contenido es muy sencillo! Utiliza el **menú principal** ubicado en la barra superior (o lateral) para navegar directamente a la materia o sección de tu interés:

1. **Selecciona tu Asignatura:** Explora el menú para desplegar el catálogo de materias de ingeniería disponibles.
2. **Elige el Tipo de Recurso:** Filtra entre apuntes, guías prácticas o exámenes resueltos.
3. **¡Comienza a Aprender!:** Descarga el material o trabaja directamente desde el portal.
